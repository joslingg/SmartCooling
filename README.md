# Smart Cooling System

## 📖 Overview

Hệ thống điều hòa vi khí hậu tự động cho khu vực nghỉ chân ngoài trời trong trường học.

## ✨ Features

- 🌡️ Đo nhiệt độ và độ ẩm
- ☀️ Phát hiện ánh sáng
- 🌧️ Phát hiện mưa
- 💨 Phun sương tự động
- 🏠 Điều khiển mái che
- 📟 Hiển thị LCD

## 📦 Hardware

- Arduino Uno
- LCD I2C 16x2
- DHT22
- BH1750
- Rain Sensor
- RCWL-0516
- MG996R Servo
- 5V Mist Maker
