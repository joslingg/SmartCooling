# Smart Cooling System

## Objective

Thiết kế hệ thống điều hòa vi khí hậu tự động cho khu vực ghế đá ngoài trời.

## Functions

- Đo nhiệt độ
- Đo độ ẩm
- Đo cường độ ánh sáng
- Phát hiện mưa
- Phát hiện người
- Điều khiển mái che
- Điều khiển máy tạo sương

| Điều kiện   | Mái  | Sương |
| ----------- | ---- | ----- |
| Nắng        | Mở   | Tắt   |
| Nắng + Nóng | Mở   | Bật   |
| Mưa         | Mở   | Tắt   |
| Âm u        | Đóng | Tắt   |
| Âm u + Nóng | Đóng | Bật   |
